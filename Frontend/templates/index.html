Tài liệu Tích hợp API (Connection Guide)

Hệ thống cung cấp REST API. Câu trả lời của /chat là luồng NDJSON (mỗi dòng một sự kiện JSON: status, delta, done…), không phải SSE. Địa chỉ máy chủ hiện tại: http://localhost:8000

📄 Mở Swagger Interactive UI (/docs) 📘 Mở ReDoc API Specs (/redoc)
Quickstart (cURL): đăng nhập lấy cookie → tạo cuộc trò chuyện → hỏi
# 1) Đăng nhập, cookie phiên lưu vào cookies.txt (tài khoản tạo ở trang /login)
curl -c cookies.txt -X POST "http://localhost:8000/api/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "ban@example.com", "password": "mat-khau"}'

# 2) Tạo cuộc trò chuyện (lấy conversation.id trong kết quả)
curl -b cookies.txt -X POST "http://localhost:8000/api/conversations" \
  -H "Content-Type: application/json" -d '{"system": "retrieval"}'

# 3) Hỏi (mode "exact" = 🎯 Tìm chính xác; bỏ mode = trò chuyện thường)
curl -N -b cookies.txt -X POST "http://localhost:8000/api/conversations/1/chat" \
  -H "Content-Type: application/json" \
  -d '{"text": "Tôi muốn làm giấy khai sinh", "mode": "exact"}'
Cho người dùng ở máy khác kết nối
  • Đặt APP_HOST=0.0.0.0 trong .env (Docker đã đặt sẵn), mở cổng APP_PORT (mặc định 8000) ở tường lửa.
  • Người dùng mở http://<IP-máy-chủ>:8000 → /login → đăng ký.
  • Dùng HTTPS thì đặt AUTH_COOKIE_SECURE=true. Muốn khoá đăng ký tự do: REGISTRATION_ENABLED=false.
  • Số người xử lý cùng lúc: QUEUE_CONCURRENCY (và OLLAMA_NUM_PARALLEL phía Ollama).
